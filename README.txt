ГИРУДО — ФАЙЛЫ ДЛЯ GITHUB

Загрузите в репозиторий все файлы этой папки.

index.html — страница сайта.
styles.css — внешний вид.
script.js — меню, форма, маска телефона, подключение Telegram.
botanical.svg — изображение пиявки.
server.js — небольшой сервер связи формы с действующим сайтом и ботом.
package.json — команда запуска сервера на Node.js-хостинге.

GITHUB PAGES
Выберите публикацию из корня репозитория. Страница откроется без сборки.
В этом варианте кнопка записи ведёт на работающий сайт, где сохраняется заявка
и подключается Telegram. Сам GitHub Pages не выполняет серверный код.
Чтобы включить публикацию, откройте Settings -> Pages -> Build and deployment.
В Source выберите Deploy from a branch, затем ветку с файлами index.html
(например main или QA) и папку /(root), после этого нажмите Save.
Адрес проекта обычно выглядит так: https://muhamed767.github.io/Girudo/.
Откройте именно адрес Pages, а не страницу Code репозитория.

ФОРМА ЗАПИСИ ПРЯМО НА НОВОМ ХОСТИНГЕ
На Node.js-хостинге (Node.js >= 22) выполните npm start.
Никаких npm-зависимостей устанавливать не нужно. Порт задаётся через PORT (по умолчанию 3000).
server.js передаёт заявки на действующий сервер
https://hirudo-care.bziksievmuhamed.chatgpt.site/ — там остаются база, бот и расписание.
Это подключение к существующему серверу, а не самостоятельная копия его базы и бота.
Действующий сайт должен оставаться доступным.

TELEGRAM
Бот: https://t.me/girudo07bot
После заявки персональная кнопка связывает запись с Telegram.
Токен бота уже настроен на действующем сервере; в GitHub его загружать не нужно.
Текущий Telegram webhook менять не требуется.
